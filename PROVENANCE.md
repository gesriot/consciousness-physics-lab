# Происхождение и ограничения распространения

2026-11-07: исходный пользовательский архив sphere-thermal-cli.zip,
SHA256 22f780b4cf2b9766c531a8e59114bb6100cf8d2b9e8e638fe8b1ebbde20808bd.
Код в vendor/sphere-thermal-cli импортирован без изменений; исключены
AppleDouble, __MACOSX и генерируемые __pycache__. Архив не содержит LICENSE.
Авторство и права на публичное распространение не установлены. Общая открытая
лицензия намеренно не назначена. До публикации требуется прояснить права.
Локальная интеграция выполнена по запросу пользователя; remote не настроен.

Перед исполнением просмотрены Python-модули, тесты, metadata сборки.
Поиск распространённых маркеров ключей/паролей, сетевых вызовов, eval/exec
не обнаружил секретов или сетевых действий в Python-коде. Это ограниченная
проверка, не гарантия отсутствия всех секретов и не аудит зависимостей.
Тесты запускают только тот же CLI через текущий Python; CLI читает JSON и
выводит JSON/диагностику. Symlink/path-traversal записи архива отклоняются.

requirements.txt исходника фиксирует numpy==2.5.4, но текущая проверка использует
уже установленный NumPy 2.3.5 (допустим по pyproject numpy>=2.0). Исходный pin
не устанавливался и не проверялся. Для воспроизведения текущей проверки см.
requirements-tested.txt. SciPy и Rust пока не требуются.

README исходника ссылается на стороннюю рукопись combustion-theory-phd;
это ссылка происхождения, а не включённый источник и не верификация рукописи.
Экспоненциальная передаточная функция не означает точный стационарный отклик
с нулевого времени: при нулевом начальном состоянии остаётся переходный процесс.
Здесь используется отношение преобразований Лапласа.
