# E004: независимая проверка значения выявила цену защиты

2026-11-07; регистрация ad0a5e4. Код: `lab/finite_volume.py`, `lab/executor.py`,
`lab/value_experiment.py`. Фактические результаты и хеши: `results.json`.
36 парных задач,5 условий,3 абляции;540 записей не являются независимой выборкой.

Конечно-объёмный решатель дискретизирует
z·V_i·u_i = C_left·(u_left−u_i) + C_right·(u_right−u_i)
при единичной температуре поверхности, нулевом потоке в центре, R=1,
kappa=1/(15T). Средний отклик — взвешенная объёмами сумма u_i. SciPy решает
комплексную трёхдиагональную систему. Это другой численный путь той же физической
модели, не независимый физический эксперимент.

## Результат абляций

Старый resolution guard принял все36 чистых ответов. Также он принял36
неверных ответов с поддельным N,36 со смещённым значением,30 с неверным T.
Оставшиеся6 ответов с неверным T приz=0 численно совпали с правильными.
Условие «искажённый отчёт планировщика» дублирует численное смещение и не
является новым независимым типом дефекта.

Независимый value_check отверг все численно неверные инъекции, но также
отверг18 из36 чистых точных ответов. Это существенная потеря полноты.
Все6 численно точных ответов wrong_time приz=0 были приняты.

Повторное исполнение плана с независимой проверкой восстановило точные значения
для всех36 задач в каждом условии. Тем не менее18 из36 снова отвергнуты:
причина в запасе точности, не в границе передачи результата.
Дополнительное исполнение требует12042 мод на каждое условие; проверка значения
решает четыре системы суммарно на960 ячейках для каждого ответа.
Это дополнительная работа, не бесплатная защита при прежнем бюджете.

## Почему отвергнуты правильные ответы

Например, T=1,z=1,tolerance=0.001: фактическая ошибка модального ответа
0.000999057, то есть он едва укладывается в допуск. Расхождение с FV равно
0.000995530, но оценка неопределённости FV ещё0.0000211633. Их сумма превышает
допуск. На больших частотах эффект сильнее. Все эти случаи прошли проверку
сходимости сеток; отказ вызван суммой расхождения и неопределённости.

Проверяющий использует2·последнюю межсеточную разность плюс эвристический
масштаб округления. Это не строгий сертификат; отсутствие ложных принятий
на разработочной сетке не доказывает их невозможность.

## Граница исполнения и ограничения

Планировщик предлагает только N. Исполнитель сам вычисляет значение по исходному
запросу и возвращает frozen receipt с N и хешем запроса. Ошибочное значение из
отчёта планировщика игнорируется при повторном исполнении. Хеш связывает запись
с запросом, но не является подписью; frozen dataclass предотвращает случайную
мутацию, но не злонамеренную подделку внутри Python. Требуется доверенный процесс.

Следующий зарегистрированный опыт: разделить допуск между решателем и
проверяющим, отдельно измерить цену новых мод и уточнения FV на другой сетке.
Не следует просто ослаблять критерий после наблюдения18 ложных отказов.
Дальнейшая граница исполнения потребует отдельного процесса и тестов транспорта.
Ни один из результатов не является свидетельством субъективного опыта.
