# Журнал разработки E004

1. Протокол сохранён коммитом ad0a5e4 до запуска основной серии.
2. Первый тест `test_detect_value_corruption` выявил ложный отказ для точного
   стационарного значения g(0)=1. Причина: межсеточные различия на уровне
   накопленного округления решателя не удовлетворяли критерию убывания.
   Общая первая проверка завершилась 1 failure среди24 лабораторных тестов;
   это произошло до запуска E004, а не после просмотра основной серии.
3. Для уровня округления добавлен эвристический масштаб32·eps·N², отражающий
   рост обусловленности диффузионной матрицы. Это не доказанная оценка.
   После исправления все54 теста проходят (24+30).
4. Основная серия выявила18 ложных отказов на36 чистых ответах. Критерий и
   сетки не изменялись для устранения этого результата. Выбор допуска
   контроллером оставляет слишком мало запаса для независимой проверки.
5. После серии добавлена валидация некорректных входных бюджетов исполнителя
   и явный счёт ячеек проверяющего. Численная часть не менялась; серия повторена
   с теми же результатами, хеши актуальных исходников сохранены в JSON.
