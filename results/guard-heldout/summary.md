# E003: независимая финальная проверка

2026-11-07. Предварительный протокол: `experiments/E003-independent-guard.md`,
коммит bd945e6. Исходники фактического запуска сохранены по SHA256 в results.json.
Серия содержит 96 новых задач на каждую из пяти неизменённых политик E002.
Численный выбор не подстраивался после просмотра этой серии.

- adaptive: 94/96 точных, guard принял94, потрачено66666 мод.
- fixed: 86/96 точных, guard принял86, потрачено142762 мод.
- budget_once: 94/96 точных, guard принял94, потрачено393216 мод.
- stale: 2/96 точных,94 ложных исходных заявления. Guard отклонил все94 неверных
  и принял2 точных ответа; потрачено6860 мод.
- irrelevant: те же численные результаты и решения, что adaptive.

Ложных принятий нет среди480 ответов на96 парных задачах. Эти ответы
зависимы по задаче и не являются480 независимыми наблюдениями. Все фактически точные ответы
приняты, включая94 точных ответа исходного adaptive. Критерий успеха E003
выполнен на этой серии. Это конечный синтетический holdout, не универсальная
гарантия и не независимая физическая валидация.

Guard получает исходный запрос отдельно от изменяемого состояния, заново
вычисляет оценку хвоста и сверяет заявленный расход с бюджетом по журналу.
Это проверка согласованности записей, а не независимое измерение выполнения. Он не использует analytic
и не доверяет прогнозу контроллера. Оценщик analytic вызывается после решения.
Консервативная оценка хвоста дополняется эвристикой округления, поэтому результат
не называется строгим интервальным сертификатом.

Важная граница: guard не проверяет произвольную порчу численного ответа или
правдивость подделанного журнала внешнего исполнителя. Если заменить значение
на неверное, сохранив допустимое N, одной оценки разрешения недостаточно.
Эта граница явно зафиксирована unit-тестом. Следующий механизм должен
проверять согласованность самого численного значения независимым способом.

Все48 тестов (18 лабораторных+30 исходного решателя) прошли. Время guard
сохраняется отдельно; микросекундные значения этой серии не используются
для вывода о скорости. Для воспроизведения:

```sh
./scripts/check.sh
python3 -m lab.heldout --output results/local/guard-heldout.json
```

После ревью добавлен отказ для неверного Python-типа запроса (None/dict).
Численная политика и критерий принятия не менялись; серия повторена с теми же
результатами, итоговый JSON содержит хеши текущей реализации.
