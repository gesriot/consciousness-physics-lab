# Внимание как распределение проверок

В этой области вниманием называется выбор следующей проверки при ограниченном
детерминированном бюджете. Самомодель – доступная для чтения и изменения таблица
надёжности, возможностей обнаружения и стоимости собственных действий.
Это операциональное продолжение EXP-001 и EXP-002 из программы исследования,
не утверждение о субъективном опыте или проверка теории сознания.

Линия проверки E001–E016 завершена подтверждающим опытом. Замороженный конвейер
P и остальные модули `lab/` используются только как инструменты, без изменений.
Новая линия имеет протоколы A001, A002 и далее в `protocols/`, результаты в
`results/`, тесты `tests/test_attention_*.py`, запускаемые общей проверкой.
Внешний архив владельца сюда не переносится.

Протокол и самомодель фиксируются отдельным коммитом раньше кода и новых данных.
Seeds и порядок заранее заданы. С первой реализации обязательны архив точных
входов, `--replay`, явный `--runtime-override`, сохранение происхождения и сравнение
повторов по рабочим решениям. Новые исходы не используются для настройки.
Положительный эффект совместим с обычным планированием. Отрицательный результат
не опровергает все возможные самомодели. Зависимые записи не считаются независимыми.

## A001

[Протокол](protocols/A001-budgeted-self-model.md), [самомодель](self_model.json),
[отчёт](results/A001/report.md). На 540 зависимых входах B не улучшила первичную
правильность относительно канонического/дешёвого порядков: 245/245/419 верных
при 30/60/100%. Ложных принятий нет. Относящаяся к делу порча изменила 346
последовательностей на каждом бюджете, но не ухудшила ни одного первичного
исхода. Нерелевантная порча не изменила действия. B дешевле простых порядков;
это ограниченный стоимостной эффект, не подтверждение сильного прогноза.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m attention.a001 --output results/local/a001.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m attention.a001 --replay results/local/a001.json --output results/local/a001-repeat.json
python3 -m attention.a001 --compare results/local/a001.json results/local/a001-repeat.json --output results/local/a001-comparison.json
python3 -m attention.build_model --output results/local/a001-reconstructed-model.json
./scripts/check.sh
```

На другой версии среды требуется содержательная причина в
`--runtime-override 'Cross-platform replay audit: actual version difference'`.
Исходный архив не перезаписывается. Сравнение отделяет точные рабочие решения
и структуру от измеренных float-диагностик. Детерминированные логические стоимости
`spent`, `full_cost` и стоимость каждого действия остаются точными. Код возврата
и поле `passed` зависят только от решений и структуры: целые числа, булевы
флаги, строки, типы, ключи и длины списков проверяются точно. Численные различия
информационные: `numeric_diagnostic_summary` содержит число сравнений и изменений,
максимальные абсолютные и относительные различия по полям, а также число
не конечных пар. Относительная разница нормирована на максимум модулей пары;
для двух нулей она нулевая. Старые `numeric_diagnostics_pass` и список различий
с допуском 1e-12 сохранены для сопоставления аудитов, но не определяют успех.
Совпадение решений не означает точного численного воспроизведения. Политики заново исполняют только выбранные
действия; подготовка полного эталона стендом не включена в экономию политики.

## A002

[Протокол](protocols/A002-shared-budget.md), [S2](self_model_s2.json),
[отчёт](results/A002/report.md). Общий бюджет 12 пакетов по 45 входов позволяет
полное принятие части входов уже при 20%. B: 153/275/390/422 верных;
C2: 261/335/422/422, поэтому общий прогноз преимущества не подтвердился.
C4: 72/257/319/319; преимущество над этой эвристикой не обобщается на всю
адаптивность. D теряет 36/82/71 при ограничении, D′ сохраняет B. Ложных принятий 0.
S2 Brier 0.3940477476 против базового 0.5543755805. Полное правило P не меняется.
Архивы результатов A002 хранятся сжатыми (`results/A002/results.json.gz` и `repeat.json.gz`);
`--replay`, `--compare` и аудит читают `.json.gz` напрямую.
Новые большие архивы можно сразу писать в `.json.gz` детерминированным gzip -9.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m attention.a002 --output results/local/a002.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m attention.a002 --replay results/local/a002.json --output results/local/a002-repeat.json
python3 -m attention.a002 --compare results/local/a002.json results/local/a002-repeat.json --output results/local/a002-comparison.json
python3 -m attention.build_s2 --output results/local/a002-reconstructed-model.json
./scripts/check.sh
```

При другой среде используется содержательный `--runtime-override`, исходник
не перезаписывается. Совпадение решений включает структуру, дискретные флаги
и логические цены, числовой дрейф диагностик сводится отдельно. Предсказания
сохраняются до вычислений; повтор читает точные входы и глобальный порядок.

Независимый пересчёт архивного результата:
`python3 -m attention.audit_a002 results/local/a002.json --output results/local/a002-audit.txt`.

## A003

[Протокол](protocols/A003-updated-knowledge.md), [отчёт](results/A003/report.md).
S3 обновляет совместные development-траектории по каждому наблюдению;
двухступенчатое планирование использует разные продолжения после разных исходов.
B2: 170/308/391/404; B: 138/268/375/404; C2: 229/308/402/404.
Оракул: 330/400/404/404. Прогноз превосходства над дешёвым порядком не выполнен.
D′ сохраняет B2; D немедленно теряет поддержку и переходит к C2, поэтому
D/D′ не является чистым сравнением устойчиво работающих моделей обновления.
Все архивы и сравнения читаются непосредственно в .json.gz. Полный повтор
не дублируется: сохранены сводка, хеш и аудит. Команды находятся в корневом README.

Архивы A001 тоже перенесены в .json.gz без изменения распакованных байтов.
`attention.a001` поддерживает прямой gzip для replay/compare, а исторические
имена .json остаются разрешимыми адаптером чтения. [Проверка](results/A001/compression-report.md).

## A004

[Протокол](protocols/A004-factorial-knowledge.md), [отчёт](results/A004/report.md).
Одна S3 во всех клетках 2×2: prior/обновление и одна ступень/дерево;
FULL-прокси одинаков. U0O 173/322/377/384, U1O 186/333/382/384,
U0T 212/335/383/384, U1T 179/303/379/384; C2 227/297/384/384.
H 68/68/68/68 не собирает предпосылки принятия. Мягкая D не вызывает
реального отказа поддержки; Dprime сохраняет исходную схему.
По критерию выигрыша на обоих малых бюджетах серия закрыта. Частный
выигрыш при 40% и сумма U0T 547 против C2 524 при 20%+40% сохраняются:
они запрещают безусловный вывод об отсутствии пользы. Реальные резервные
сбросы и предиктивные расширения отсутствуют; гипотетические расширения
не выдаются за эмпирическое знание S3. Команды воспроизведения в README корня.
