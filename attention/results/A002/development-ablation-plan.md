# План послерезультатного разложения A002

Этот план записан после просмотра A002 и оракульной сводки, но до запуска
описанных ниже четырёх вариантов. Это development-анализ, не регистрация
независимого подтверждения. Новые данные A003 не используются.

Общая модель четырёх вариантов строится только по 60 запросам A001.
Для запроса выбираются 16 ближайших запросов по признакам S2; девять полных
траекторий каждого запроса имеют одинаковый исходный вес. Истинная точность
и исходы действий доступны только как обучающие метки A001. Политика получает
из A002 только запрос, цену и уже наблюдённые категориальные вердикты.
Отсутствующее в обучающем пути действие имеет категорию «не наблюдалось».

Фактор обновления: неизменные исходные веса либо последовательное умножение
на 0.95 при совпадении наблюдённого вердикта с обучающей траекторией и на 0.025
при несовпадении, затем нормировка. Это сглаженная модель наблюдения; значения
не подбираются по исходам четырёх запусков.

Фактор распределения: сначала вход по ожидаемой разрешимости / полной оставшейся
цене, затем действие; либо единый глобальный выбор действия. В обоих вариантах
оценка действия равна (вероятность верного обнаружения + 0.05 × вероятность
принятия отдельного действия) / цене. Вариант без обновления с приоритетом входа
лишь структурный аналог B: он использует другую общую модель, поэтому его нельзя
выдавать за точное воспроизведение B. Дополнительного отказа от входов нет.
Все четыре варианта сохраняют доступность действий и строгое правило принятия.

Симуляция считывает ответ выбранного действия из полного архива A002, но
планировщику полный архив не передаётся. Сравниваются 20/40/60/100% и
попарные различия по 12 пакетам. Записываются эффекты каждого фактора при
обоих уровнях второго и взаимодействие. Единственный причинный процент
проигрыша исходной B из такого анализа не выводится.
