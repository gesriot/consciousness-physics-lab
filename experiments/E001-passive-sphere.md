# E001: воспроизведение пассивного теплового инструмента

Статус: выполненная исходная проверка реализации, не эксперимент о сознании.
Модель: однородный инертный шар, постоянная температуропроводность, идеальный
контакт, заданная температура поверхности, нулевое начальное состояние.
Нет химической реакции и обратной связи с внешней средой.

Критерий: исходные unittest проходят; CLI выдаёт документированные коды для
обычных, недостаточно точных и недопустимых запросов. Дополнительно runner
сохраняет ошибки, хеш входа, среду и измеренное время.

Команды: `./scripts/check.sh`; `python3 -m lab.runner
vendor/sphere-thermal-cli/examples/single_compare.json`.
Фактические результаты: `results/baseline/`; исходники привязаны git-коммитами.
Время включает импорт Python/NumPy и IPC; это не микробенчмарк ядра и не
сравнение языков. Для решения о Rust нужны профиль горячего пути, размеры
целевых задач, многократные измерения, память и одинаковая точность.

Ограничения: сравниваются представления одной математической модели;
нет измерений на физическом шаре. Эвристическая погрешность округления не
является строгим интервальным сертификатом. Размер JSON на входе CLI не
ограничен: не выставлять как публичный сервис без дополнительных лимитов.
