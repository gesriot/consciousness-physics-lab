# E006: новые дефекты на отложенной сетке

Предварительная регистрация, 2026-11-07, до генерации задач.
Замораживаем стратегию D из E005: половина допуска для выбора N, максимум
4096 мод; FV64..4096, максимум8128 суммарных ячеек; исходный допуск финального
решения; тот же эвристический критерий сходимости и неопределённости.

Новая выборка96 задач, seed20261112. Независимо:
log10(T)~U[-2,2],log10(|zT|)~U[-6,5],arg(z)~U[-pi/2,pi/2],
log10(tolerance)~U[-4,-1]. Более широкий частотный диапазон намеренно повышает
трудность по сравнению с E005. Порядок условий перемешивается seed20261113.
Первый stale-ответ берётся из заранее заданного запроса z=1,T=1,tolerance=.01;
для остальных — из предыдущей задачи, с её собственным нормальным выбором N.

Шесть условий:
1. Чистое значение текущего исполнителя.
2. Комплексное сопряжение значения (ошибка знака фазового отклика).
3. Молчаливая нормировка усечённых мод на сумму их статических весов.
4. Ошибка единиц времени: вычисление при1000T.
5. Добавка1.25·исходный_допуск к действительной части значения. Часть таких
   инъекций может случайно компенсировать прежнюю ошибку; это не ложная тревога,
   если итоговое значение действительно удовлетворяет допуску.
6. Устаревшее значение предыдущего запроса с текущими заявленными N и запросом.

Инъекции проводятся на входе проверяющего, после честного выполнения плана.
Они моделируют повреждение транспорта/отчёта, а не выдаются за подлинные
неизменяемые квитанции. Число мод журналируется как заявленное для переданного
значения; генерация инъекций и её цена записываются отдельно.

Абляции: только E003 resolution guard и полный D (resolution+FV).
Общий вход у обоих один и тот же; ошибки классифицируются по фактической
абсолютной ошибке относительно analytic после решений. Не считать каждый
внедрённый дефект численной ошибкой, если итоговый ответ остаётся точным.

Первичная мера: ложные принятия фактически неточных ответов по каждому типу.
Вторичные: ложные отказы точным, точные принятые чистые ответы, заявленные моды,
FV-ячейки, время проверки, отдельная цена инъекций. Предсказание: D уменьшит
ложные принятия относительно resolution-only; частотное расширение может
увеличить отказы. Нулевые ошибки на серии не считаются универсальной гарантией.

96 задач сопоставляются попарно между условиями;1152 записи не являются
независимой выборкой. Параметры после просмотра не меняются. Неудачи сохраняются
как результат; исправления требуют нового протокола и новой серии.
