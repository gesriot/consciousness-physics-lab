# Сознание и агент-физик: исследовательская лаборатория

Рабочий репозиторий долгосрочного исследования. Здесь соединяются строгая
постановка задач, понятное объяснение и проверяемый лабораторный журнал.
Это не готовая диссертация и не утверждение о создании сознания.

## Начать

Python 3.10+; проверено на Python 3.12.14 / NumPy 2.3.5.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements-tested.txt
./scripts/check.sh
python3 -m lab.runner vendor/sphere-thermal-cli/examples/single_compare.json > results/local-run.json
```

Последняя команда делает три измерения времени CLI вместе с запуском Python.
Это минимальная основа инфраструктуры будущего агента: пока только
детерминированный вызов физического инструмента и протоколирование результата.
Этот исходный runner не содержит LLM; следующий вычислительный контроллер описан ниже.

## Правила

Отделять факт наблюдения, вычислительный вывод, интерпретацию и гипотезу.
У каждой численной записи должны быть вход, версия кода, окружение, единицы и
критерий успеха. Отрицательные результаты сохранять. Сначала регистрировать
протокол, затем запускать. Исправления оформлять отдельными коммитами.
Нельзя считать согласие двух формул независимой физической валидацией.
Нельзя считать правдоподобный самоотчёт доказательством сознания.

валидация выбранных по ним улучшений. [Наблюдения](MANUSCRIPT.md#10-что-мы-уже-наблюдали)
и [разведочный анализ](results/development-verifier/summary.md).

E007 имеет отдельные коммиты протокола, реализации и результатов:
[протокол](experiments/E007-verifier-stress.md),

На 192 новых задачах U не покрыла ошибку FV на 101/768 уникальных шагов,

выявления нарушения; точных принятий не потеряло. Отдельный теневой путь

## Воспроизведение E007 и E008

По умолчанию требуется ровно Python 3.12.14 / NumPy 2.3.5 / SciPy 1.17.0
и чистые отслеживаемые файлы. Сначала коммит протокола, затем коммит
реализации, затем генерация данных. Новые JSON сохраняют версии, ОС,
архитектуру, конфигурацию BLAS/LAPACK NumPy и SciPy, git_head,
protocol_commit, protocol_sha256 и хеши исходников. Старые архивы неизменны;
отсутствующие сведения об их платформе не восстанавливаются догадкой.

Точное совпадение нетайминговых полей относится к повторам на исходной
платформе и исходной реализации, а не ко всем ОС и библиотекам. Владелец
проверил macOS arm64 / Python 3.12.13 / NumPy 2.3.5 / SciPy 1.17.0:
вердикты, решения, метки и счётчики совпали, числа различались примерно
на 10⁻¹⁴. В E008 повторная генерация входов дала другие хеши из-за последнего
бита libm. Это сообщение владельца, не новый сохранённый результат этого
репозитория и не доказательство переносимости на любую платформу.

Для межплатформенной проверки используйте сохранённые запросы, а не только
seed. `--replay` читает E007 tasks или E008 intake_channel из results.json,
сохраняет двоичные значения входных float, проверяет входные хеши E008 и
записывает SHA-256 всего исходного архива. Порядок условий остаётся задан
зарегистрированным order_seed. В E007 масштаб |zT| для анализа покрытия
восстанавливается из сохранённого запроса; это может изменить последний бит
производной величины относительно первоначального сэмплирования.

```sh
./scripts/check.sh
python3 -m lab.verifier_stress --replay results/verifier-stress/results.json --output results/local/e007-replay.json
python3 scripts/compare_experiment_runs.py results/verifier-stress/results.json results/local/e007-replay.json --mode decisions --rtol 1e-12
python3 -m lab.common_mode --replay results/common-mode/results.json --output results/local/e008-replay.json
python3 scripts/compare_experiment_runs.py results/common-mode/results.json results/local/e008-replay.json --mode decisions --rtol 1e-12
```

На другой версии Python добавьте к запуску явно обоснованный
`--runtime-override 'Cross-platform replay audit: Python 3.12.13'`.
Причина и фактические версии сохраняются в новом JSON; проверка чистоты
отслеживаемых файлов остаётся обязательной. Существующий выходной файл
не перезаписывается: выберите новый путь. Архивы результатов не обновляются.

Режим сравнения по умолчанию `--mode exact` оставляет точное сравнение
всех нетайминговых полей, включая происхождение. `--ignore-git-head`
исключает только HEAD позднего коммита. После изменения реализации старые
хеши исходников закономерно отличаются, и exact не должен проходить.
В режиме `--mode decisions` только float сравниваются с относительным
допуском (по умолчанию 10⁻¹², абсолютный допуск ноль). Даже малое
расхождение около нуля может не пройти чисто относительную проверку;
допуск автоматически не расширяется. Все строки, булевы
решения, метки, целые счётчики, структура, seeds, входные хеши и идентичность
протокола обязаны совпадать точно. Среда, HEAD, хеши исходников, сведения
о replay и разрешённом отклонении версий сравниваются отдельно и все
различия явно печатаются. PASS decisions не означает совпадения
происхождения или точного воспроизведения. В обоих режимах исключаются
из сравнения поля с окончанием seconds. Дополнительная послерезультатная проверка
E007: `python3 scripts/audit_e007_high_precision.py` из корня репозитория,
требует необязательный mpmath 1.3.0, использует 60 десятичных знаков.
Она не меняет основной закреплённый стек или зарегистрированные меры.

Материалы внимания остаются отдельным архивом и в эти опыты не включались.

## Ошибка геометрии при сохранённых инвариантах

E010: 96 новых задач, шар/пластина/цилиндр с одинаковым средним временем T.
D допустила 33 неточных принятия пластины и 27 цилиндра; исходный хеш,
нормировка и первый момент их не устранили. Второй момент и высокочастотный
признак каждый выявили все 192 подмены без дополнительных чистых отказов.
С D ложных принятий нет, но сохранён один отказ чистому точному ответу;
также отклонены 122 случайно точных значения неверной геометрии.
Полнота обнаружения не заявляется.
[Протокол](experiments/E010-geometry-invariants.md),
[отчёт](results/E010-geometry-invariants/summary.md).
Повтор: `python3 -m lab.geometry_invariants --output results/local/e010.json`.
