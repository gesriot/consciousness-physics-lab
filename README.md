# Сознание и агент-физик: исследовательская лаборатория

Рабочий репозиторий долгосрочного исследования. Здесь соединяются строгая
постановка задач, понятное объяснение и проверяемый лабораторный журнал.
Это не готовая диссертация и не утверждение о создании сознания.

## Начать

Python 3.10+; проверено на Python 3.12.14 / NumPy 2.3.5.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements-tested.txt
./scripts/check.sh
python3 -m lab.runner vendor/sphere-thermal-cli/examples/single_compare.json > results/local-run.json
```

Последняя команда делает три измерения времени CLI вместе с запуском Python.
Это минимальная основа инфраструктуры будущего агента: пока только
детерминированный вызов физического инструмента и протоколирование результата.
Этот исходный runner не содержит LLM; следующий вычислительный контроллер описан ниже.

## Правила

Отделять факт наблюдения, вычислительный вывод, интерпретацию и гипотезу.
У каждой численной записи должны быть вход, версия кода, окружение, единицы и
критерий успеха. Отрицательные результаты сохранять. Сначала регистрировать
протокол, затем запускать. Исправления оформлять отдельными коммитами.
Нельзя считать согласие двух формул независимой физической валидацией.
Нельзя считать правдоподобный самоотчёт доказательством сознания.

## Следующий шаг: численный агент

`python3 -m lab.scientist --output results/local/scientist.json` запускает

Это детерминированный контроллер научного расчёта, не LLM и не тест переживания.

## Независимая проверка итогового допуска

`python3 -m lab.heldout --output results/local/guard-heldout.json` воспроизводит

`results/guard-heldout/summary.md`. Guard проверяет разрешение и бюджет,
но не произвольную порчу численного ответа.

## Независимая проверка численного значения

исполнения. Он обнаружил внедрённые численные ошибки, но отклонил половину

`python3 -m lab.fault_holdout --output results/local/fault-heldout.json`
запускает E006: новые ошибки фазы, нормировки, единиц и устаревшего значения

но сохранился один отказ чистому точному ответу. Результаты:
`results/fault-heldout/summary.md`.


## Трёхзначный вердикт и стресс оценки

E005/E006 теперь development-данные: прежние хеши регистрации относятся к
неопубликованной истории, поэтому порядок регистрации по этому репозиторию
проверить нельзя. [Поправка и наблюдения](MANUSCRIPT.md#10-что-мы-уже-наблюдали)
и [разведочный анализ](results/development-verifier/summary.md).

E007 имеет отдельные коммиты протокола, реализации и результатов:
[протокол](experiments/E007-verifier-stress.md),
[сводка](results/verifier-stress/summary.md).
На 192 новых задачах U не покрыла ошибку FV на 101/768 уникальных шагов,
все при δ/h<0.5 и без сходимости. На решающих шагах промахов не было.
D3 сохранила ноль ложных принятий и использовала 5 313 536 ячеек решения
против 7 257 088 у D. Правило бесперспективности потеряло 34 последующих
выявления нарушения; точных принятий не потеряло. Отдельный теневой путь
и зависимые записи учитываются отдельно.

## Общая ошибка двух решателей

В E008 двухрешательная D приняла 171 неверную запись при общей порче запроса
или масштаба модели на 96 новых задачах. Независимый исходный хеш запроса
и инварианты G(0)=1, −G′(0)=T вместе с D устранили эти ложные принятия,
без дополнительных отказов чистым входам, но отвергли 81 случайно точную порчу
(65 дополнительных отказов относительно D). Их стоимость и границы:
[протокол](experiments/E008-common-mode.md),
[сводка](results/common-mode/summary.md). Это не универсальная гарантия.

## Воспроизведение E007 и E008

Требуется ровно Python 3.12.14 / NumPy 2.3.5 / SciPy 1.17.0 и чистые
отслеживаемые файлы. Сначала коммит протокола, затем коммит реализации,
затем генерация данных. JSON сохраняет git_head, protocol_commit,
protocol_sha256 и хеши исходников.

```sh
./scripts/check.sh
python3 -m lab.development_analysis --output results/local/development.json
python3 -m lab.verifier_stress --output results/local/e007.json
python3 scripts/compare_experiment_runs.py results/verifier-stress/results.json results/local/e007.json --ignore-git-head
python3 -m lab.common_mode --output results/local/e008.json
python3 scripts/compare_experiment_runs.py results/common-mode/results.json results/local/e008.json --ignore-git-head
```

Параметр --ignore-git-head разрешает только различие HEAD позднего коммита
документации/результатов; хеши протоколов и исходников продолжают сравниваться.
Без этого параметра сравниваются и HEAD. В обоих случаях исключается только
время (поля с окончанием seconds). Дополнительная послерезультатная проверка
E007: `python3 scripts/audit_e007_high_precision.py` из корня репозитория,
требует необязательный mpmath 1.3.0, использует 60 десятичных знаков.
Она не меняет основной закреплённый стек или зарегистрированные меры.

Материалы внимания остаются отдельным архивом и в эти опыты не включались.
