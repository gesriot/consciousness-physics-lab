# B006: genuine counterexample or false objection

## Registered scope and sequence

This experiment tests the functional use of a model of one's own checks when
choosing between revising a premise and rejecting an observation. It does not
implement an attention schema, cortex, subjective experience or a consciousness
theory. It uses inherited provenance labels L only. The representation question
closed by B004 and B005 is not reopened on those data.

The laboratory and its tests are committed first, this protocol second, policy
and runner code next, development data and audits next, a separate freeze next,
and only then new confirmation data. Confirmation data and audits are committed
before reports or manuscript numbers. Negative development and original failed
audits are retained. No confirmation is run unless the development gates below
pass. No parameter changes are allowed after confirmation outcomes are viewed.

## Laboratory and environments

An independent unit is a series of 32 ordered episodes on one B005 physical
intake, graph, claim identities and provenance. The 44 claims include shared and
private grounds and depths 1 through 4. Physical faults reset between episodes;
learned diagnostic counters persist. This is not cumulative physical damage.
The source laboratory and diagnosis services are imported from B005 without
changing their files. Synthetic reference values retain its independent
60-decimal formula. The error tolerance is its absolute 1e-10 and relative 1e-5.

Each episode is clean without a signal with probability 0.125. Conditional on
being nonclean, the objection is false with probability 0.15 in low environments
or 0.65 in high environments; otherwise one of units, version, regime and
intermediate-method corruption is chosen uniformly. Scope is shared or private
with equal probability. Measurement and conflict-message branches alternate by
episode index. False objections have healthy accepted claims: an observation is
offset, or a conflict message names a healthy comparison. The supplied signal
is a report requiring a paid check, not an invitation to use the hidden evaluator
or free full-recipe execution to dismiss it. A false conflict can name equal
stored endpoints; no policy uses that numerical equality to bypass the common
signal-service interface. The interpretation is unreliable incoming reports,
not an internally exact equality comparator.

The four series environments cross low/high false objections with zero/moderate
check error. Conditional false-good / false-bad probabilities are:

| Channel | Zero | Moderate |
| --- | --- | --- |
| Catalog-source comparison | 0 / 0 | 0.18 / 0.12 |
| Local re-derivation | 0 / 0 | 0.12 / 0.18 |
| Repeated observation or conflict report | 0 / 0 | 0.10 / 0.15 |

A false-good report misses a real defect; false-bad reports one when the tested
proposition is healthy. For repeated observation, bad means discrepancy persists.
Each repetition uses a fresh independent attempt. Stateless keyed pseudorandom
streams use episode seed, check kind, identity and attempt number, shared across
policies. Independence is a modeling assumption, not established instrument
behavior. No persistent common-mode measurement bias is modeled here.

Neither environment nor true probabilities, culprit, clean catalog, evaluator
truth, true error events or fault class are exposed to the policy. Binary probes
return only their report. Certified source replacement after an accusation uses
the catalog; rebuilding each descendant pays the B005 cost. Repair itself is
not noisy. This is a limitation: false accusations can waste work even when the
certified repair leaves correct values correct. A binary probe does not provide
a free authoritative second answer. A local consistent re-derivation validates
only its own method, not its parents.

## Policies and paid actions

All policies use the same L provenance, candidate-set construction and public
records. Measurement grounds intersect; conflict grounds unite. D is the B005 L
rule unchanged except that its service reports can now err. One check is final,
then a bad ground is accused and its descendants rebuilt when affordable. D
repeats a measurement last after exhausting candidate grounds; as in B005, its
conflict branch does not repeat the observation after exhaustion. R first
repeats the incoming observation or conflict report, then uses D if it persists.
These branch differences are explicit parts of the compared fixed rules.

K uses D's choices but repeats a selected check until k reports agree out of at
most m. The global development options are (k,m) = (1,1), (2,3), (3,5). Either k
bad or k good reports resolves that test. With no agreement within m, or no
remaining budget, stop under suspicion rather than skip to a different ground.
K otherwise retains D's branch behavior. N makes no checks or revisions.

P maintains hypotheses for each candidate ground and for a false observation.
Initial prior mass is 0.8 distributed uniformly over candidate grounds and 0.2
on false observation; with no grounds the latter is the only hypothesis. A
source/local probe has expected bad outcome when its candidate is the culprit;
a repeated observation has expected bad outcome for any ground hypothesis.
Bayes updates use the inferred reliability by channel. Scores and probabilities
used to choose an action are rounded to 9 decimal places, with a deterministic
kind/identity ordering for ties. The next affordable check maximizes expected
reduction in Bayes classification loss per unit cost; 0-1 diagnostic loss is
1 minus the largest posterior probability. P records its posterior confidence
before each terminal decision, including an abstention label if no decision is
supported. A hypothesis is selected only when it reaches the registered
threshold. Any repeated test is charged again.

A finite global P development grid has four options: sensitivity / false-positive
Beta priors (8,2)/(1,9) or (99,1)/(1,99), crossed with threshold 0.80 or 0.95.
P starts every independent series from the same selected configuration. Within
a series, priors and channel Beta counts are updated only after an observably
resolved episode, using its posterior fractional responsibilities and accumulated
binary reports. Unresolved episodes do not teach the model. Inferred labels are
not truth labels: such self-training can reinforce mistaken diagnoses. No
hidden evaluator label may enter adaptation. All sufficient statistics and the
resolution condition are recorded for independent reconstruction.

Px uses the same architecture with reliability wrongly fixed at near-perfect
sensitivity 0.999999 and false-positive probability 0.000001, rather than learned
channel values. Px-prime changes the same number of entries in an auxiliary
unused channel; all active inputs and decisions remain P's. The same volume of
parameter edits is not evidence of equal semantic impact; that difference is
the intended intervention. The implementation must record both parameter views.

Costs and budgets are B005 costs, including 30 for a data-source comparison,
100 for a method-source comparison, local operation cost plus 1, and full
recursive descendant reconstruction. Repeating the observation costs two budget
units, as in B005. Source installation is included in the paid comparison and
subsequent repair workflow. Budgets are 2, 8 and 32 B005 units per episode. No
negative balance, hidden extra check, free repeated calculation or unused-budget
continuation is allowed. No accepted claim is withdrawn merely because it is
suspected or because its repair cannot be afforded. Suspicion is recorded
separately. False accusation requires an innocent ground to be named AND at
least one descendant actually revised; an unaffordable attempted accusation is
reported separately.

## Development selection, exposure and freeze

Development seeds are 20270501 through 20270512 inclusive, each in all four
environments. Confirmation seeds are 20270601 through 20270612 inclusive, never
used in development. Episode streams are deterministic from their series seed
and environment. Every policy/configuration sees paired inputs and error streams.
All 32 episodes of one series are dependent observations, not independent runs.

Development evaluates the three K settings and four P settings globally, not
per environment. K's setting and the strongest single fixed rule among D, R and
K are chosen by lexicographic aggregate totals of false accusations, remaining
bad claims, lost good claims, then cost, with stable textual identifiers as final
ties. This fixed-rule selection is made once for all environments and budgets.
Fixed-rule declared correctness probabilities for calibration are their
observed development accuracy, frozen before confirmation, not fitted on it.

A P configuration qualifies only when all gates hold:

1. Real corruption and false objections occur with usable signals. Each retained
   real-fault scope/type has at least 20 affected accepted claims and at least
   one initially incorrect claim across development, following B001 exposure.
   Every signal branch and depth 1 through 4 is represented.
2. Moderate environments contain observed false-good and false-bad checks, and
   both low/high frequencies contain false objections. D falsely accuses an
   innocent ground at least once in moderate environments.
3. P differs in actual actions from each of D, R and selected K, including a
   changed repeated-check or observation-repeat decision. Px changes P's action
   at least once; Px-prime preserves all P actions and protected outcomes.
4. In low-zero development, P is no worse than D on ALL FOUR primary metrics
   (false accusations, remaining bad claims, lost good claims and cost), in each
   budget by signal-branch cell. A cheaper or more accurate aggregate cannot
   hide a worse cell. This is a strict admission gate, not an assumed result.

Among qualifying P configurations choose the same global lexicographic primary
ranking, then configuration identifier. If none qualifies, record the negative
development result and stop before confirmation. The finite grid is not expanded
on confirmation. If a genuine design degeneracy is identified on development,
any repair is separately documented, committed and rerun before freeze; the
existing development outcomes remain visible. No failed design is relabeled a
successful confirmation.

The freeze records selected K and P parameters, strongest fixed rule, fixed-rule
confidence estimates, all development gates and hashes. It is committed before
confirmation execution. The confirmation closure rule compares the globally
selected fixed rule with P in every environment by budget by signal-branch cell:
if the fixed rule is no worse on all four primary measures in every cell, an
explicit reliability model is unnecessary for diagnosis in this laboratory.
Otherwise specify the exact cells and prices of P's advantage; non-dominance
alone is not blanket superiority. The gate's zero-error expectation is not a
claim about untested distributions.

## Measures and predictions

Primary cell measures are false accusations, incorrect claims left accepted,
initially correct claims withdrawn or replaced incorrectly at the end, and total
price. Secondary measures are false objections rejected without revising grounds,
real counterexamples accepted and corrected, checks and repeated checks, final
suspicion, attempted accusations, depth and shared/private scope, and Brier score
and a calibration curve. P's recorded final probability is scored against whether
its selected diagnosis is correct; abstentions are shown separately, not silently
removed. Fixed policies use their frozen development accuracy. Calibration bins
are [0,.1), [.1,.2), ..., [.9,1]. Report sample counts and independent series counts.

Predictions registered before outcomes: P is no worse than D in low-zero;
moderate check errors cause D false accusations and P should reduce them at no
greater price; frequent false objections favor cheap strong R, while P should
approach the best fixed rule without environment-specific tuning. Px should lose
any benefit whereas Px-prime should preserve it. N falsely accuses nobody but
retains all original errors. Failed predictions and all tradeoffs remain results.

## Reproduction and data integrity

The runner supports --runtime-override and a last-bit perturbation mode from its
first code commit. First runs, ordinary replays and noisy replays run sequentially,
never concurrently. Write each completed series immediately. Preserve compressed
canonical JSON with gzip level 9 and timestamp 0; manifests contain SHA-256 of
both compressed bytes and unpacked canonical JSON. Protected choices, verdicts,
integer prices/counts, inputs and protocol identity compare exactly. Numerically
unstable diagnostics are reported separately without weakening decision checks.

An independent auditor reconstructs each paid report stream, state transition,
price, posterior and final metric from inputs, stored actions and registered
rules. It must not obtain decisions by importing the policy simulation function.
All laboratory tests, targeted tests, ordinary aggregate checks and noisy checks
must pass; logs and original failures are retained. Repository growth is below
60 MB, no new blob exceeds 50 MB, and no historical lab/attention code is changed.
